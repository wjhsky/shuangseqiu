# 🎰 双色球预测分析系统

一个基于历史号码数据的双色球智能分析预测软件，通过统计最近号码的出现频率来提供预测建议。

## ✨ 主要功能

### 1. **逐位分析** 
- 单独分析红球的每一位（第1-6位）
- 单独分析蓝球
- 统计每位数字出现的频次
- 识别热点号码和冷号

### 2. **数据可视化**
- 为每一位生成频次分布柱状图
- 清晰展示各号码的出现规律
- 支持交互式图表操作

### 3. **智能预测**
- 根据历史频率生成预测号码
- 优先推荐出现频率高的号码
- 结合冷号补充提高多样性

### 4. **详细统计**
- 显示频次最高的号码及出现次数
- 列出热点号码（出现3次及以上）
- 列出冷号候选（出现少的号码）
- 历史数据表格展示

## 📊 分析维度

### 红球分析（6位）
- **第1位分析**：统计各号码在红球第一位出现的频率
- **第2位分析**：统计各号码在红球第二位出现的频率
- **第3位分析**：统计各号码在红球第三位出现的频率
- **第4位分析**：统计各号码在红球第四位出现的频率
- **第5位分析**：统计各号码在红球第五位出现的频率
- **第6位分析**：统计各号码在红球第六位出现的频率

### 蓝球分析
- 统计蓝球号码的出现频率（01-16）

## 🚀 使用方法

### 方式一：使用示例数据
1. 打开 `index.html` 文件
2. 点击 **"加载示例数据"** 按钮
3. 点击 **"开始分析"** 按钮
4. 查看分析结果

### 方式二：输入自己的数据
1. 在文本框中按以下格式输入号码：
   ```
   红1,红2,红3,红4,红5,红6,蓝
   ```
   
2. 示例：
   ```
   03,12,25,31,32,33,06
   01,08,15,24,29,31,08
   05,14,22,27,30,32,10
   ```
   
3. 每行输入一期，最多支持20期
4. 点击 **"开始分析"** 按钮

## 📋 号码范围

- **红球**：01 - 33（共33个号码）
- **蓝球**：01 - 16（共16个号码）

## 📈 分析方法

### 频次统计
- 统计每个号码在历史数据中出现的次数
- 计算出现的频率

### 热点号码
- 定义：出现3次及以上的号码
- 推理：历史上频繁出现的号码可能会继续出现

### 冷号推荐
- 定义：出现0-1次的号码
- 推理：长期未出现的号码可能会补出

### 预测建议
- 综合各位的频率数据
- 优先选择频率高的号码
- 必要时补充冷号增加多样性
